# finite-integral-ra

This repository formalizes the number of finite integral relation algebras up to isomorphism through
7 atoms, a total of 344,814,057,187 relation algebras. These statements come from
[CSLib](https://github.com/leanprover/cslib/), and the original proofs were generated by Claude in a
session orchestrated by Fable 5.2 over about 14 hours. This used about 1.9 million output tokens.

For efficiency reasons, these proofs use a certificate system, with the Lean files being generated
by the `certgen` Rust development. The script `scripts/check-regen.sh` is offered as a wrapper to
regenerate all of these solutions in a temporary directory and confirm identical output. Please note
that the `certgen` README is AI-generated.

The generated certificates are committed to this repo so you may build as a normal Lean library, and
we provide a standard Comparator setup. On a 6-core / 12-thread AMD Ryzen AI 5 PRO 340 with
86 GiB of RAM, `lake --no-cache build Solution` took 26 minutes with fresh project artifacts and
cached dependencies. The previous certificate took 70 minutes under the same conditions.
